# Security policy

## Supported versions

Only the latest release of PocketDeck gets security fixes.

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report it privately through GitHub instead: go to the repository's **Security** tab and choose **Report a vulnerability** ([direct link](https://github.com/MohammedAbidNafi/Pocket-Deck/security/advisories/new)). Include what you found, how to reproduce it, and the PocketDeck version.

You should get a reply within a week. Once a fix is released, the report can be published as a security advisory, with credit to you if you'd like.

## Scope

In scope: the PocketDeck app and the vendored streaming engine in `moonlight/` as built here, including pairing, certificate handling and network code.

Issues in upstream projects (Moonlight, Sunshine, emulators) should be reported to those projects. If one affects PocketDeck, a report here is welcome too.
